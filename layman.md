Ragkit lets you build a searchable knowledge base from your own text files — no cloud service, no account, and no AI model required. You point it at a folder of documents, it reads and indexes them, and then you can ask questions or search for relevant passages in plain English. It works entirely on your computer, returns grounded answers with citations showing exactly which file each answer came from, and can slot into automated workflows or AI agent setups via a standard command-line interface.
